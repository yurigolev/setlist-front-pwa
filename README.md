# Setlist

Локальная PWA-библиотека репертуара для музыканта. Хранит песни, заметки, изображения аккордов и один MP3-плейбэк на песню прямо на устройстве — без аккаунта, сервера и синхронизации.

Основная цель MVP: после первого запуска с сетью установленное приложение должно открываться, искать сохранённые песни и воспроизводить вложения в авиарежиме.

## Возможности

- создание и редактирование песен: название, исполнитель, свободные заметки;
- локальное хранение метаданных и файлов в IndexedDB;
- изображения аккордов в PNG, JPEG и WebP;
- один MP3-плейбэк на песню и встроенное воспроизведение;
- поиск по названию, исполнителю и заметкам без сетевых запросов;
- сортировка по алфавиту или дате изменения, фильтр песен с плейбэками;
- устанавливаемая PWA с offline app shell.

## Технологии

- Vue 3, TypeScript и Vite;
- Vue Router и Pinia;
- IndexedDB через `idb`;
- Vite PWA / Workbox;
- Vitest.

Требуется Node.js 22 или новее.

## Быстрый старт

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Обычный dev-сервер подходит для разработки интерфейса, но не для проверки офлайн-работы.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить сервер разработки |
| `npm run build` | Проверить типы и собрать production-версию |
| `npm run preview` | Открыть локальный production-preview |
| `npm run test` | Запустить тесты один раз |
| `npm run test:watch` | Запустить тесты в watch-режиме |

## Проверка PWA на iPhone

Для офлайн-приёмки используйте production-сборку, а не `npm run dev`:

```sh
npm run build
npm run preview -- --host ::1 --port 4173 --strictPort
```

Чтобы открыть preview на iPhone из внешней сети, во втором терминале поднимите временный Cloudflare Tunnel:

```sh
cloudflared tunnel --url 'http://[::1]:4173' --no-autoupdate
```

Откройте выданный `https://*.trycloudflare.com` адрес в Safari, выберите «На экран Домой», дождитесь первого запуска с сетью, затем перезапустите приложение в авиарежиме. Подробнее о туннеле — в [TUNNEL.md](TUNNEL.md).

## Данные и ограничения MVP

Все данные остаются в браузерном хранилище конкретного устройства. Очистка данных Safari, смена браузера или устройства удалит доступ к библиотеке: экспорта, аккаунтов и синхронизации пока нет.

Поддерживаются изображения `PNG`, `JPEG`, `WebP` и аудио `MP3`. Ограничения PWA и доступный объём проверяются на целевом iPhone; приложение запрашивает persistent storage, но браузер может отказать.

## Структура проекта

```text
src/
  components/     UI и список вложений
  domain/         доменные типы песни и вложения
  repositories/   IndexedDB-адаптеры
  services/       поиск, валидация файлов и статус хранилища
  stores/         состояние библиотеки (Pinia)
  views/          экраны библиотеки, песни и редактирования
openspec/         спецификация и план MVP
```

## Статус

Реализованы основа PWA, библиотека, карточка и редактирование песни, локальные вложения, поиск и офлайн app shell. Открытыми остаются приёмка системного выбора файлов на iPhone, проверка сценария на библиотеке из 20–30 реальных песен и smoke-тесты ключевых пользовательских путей. Полный план находится в [openspec/changes/bootstrap-mvp0-mac-library/tasks.md](openspec/changes/bootstrap-mvp0-mac-library/tasks.md).

## Подключение Git-репозитория

Каталог пока не является Git-репозиторием. Перед первой публикацией проверьте сборку, создайте репозиторий в GitLab/GitHub и передайте его URL. Затем можно инициализировать Git, добавить remote и создать рабочую ветку по принятым правилам команды.

Не добавляйте в репозиторий `node_modules`, сборочные артефакты, локальные настройки IDE и временные файлы туннеля — они уже исключены в `.gitignore`.
