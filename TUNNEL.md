# Временный публичный туннель

## Что это

Cloudflare Quick Tunnel выдаёт временный HTTPS-адрес вида `*.trycloudflare.com` и проксирует production-preview на этом Mac. Благодаря этому Setlist можно открыть на iPhone без публикации приложения в интернет.

Туннель живёт, пока на Mac работают и Vite, и `cloudflared`. Адрес генерируется заново после каждого перезапуска и не предназначен для постоянной публикации.

## Текущий адрес

<https://accessory-reproduce-ctrl-mae.trycloudflare.com>

Создан: 2026-09-23. Целевой сервер: `http://[::1]:4173` (production-preview).

## Как запустить заново

Для обычной разработки можно запускать `npm run dev`. Но проверять PWA и авиарежим нужно только через production-preview: он заранее сохраняет весь JS/CSS-бандл, поэтому приложение открывается без сети.

В первом терминале из корня проекта:

```sh
npm run build && npm run preview -- --host ::1 --port 4173 --strictPort
```

Во втором терминале:

```sh
cloudflared tunnel --url 'http://[::1]:4173' --no-autoupdate
```

Cloudflare выведет новый URL в строке `Your quick Tunnel has been created! Visit it at ...`. Его нужно открыть на телефоне. Vite уже разрешает поддомены `trycloudflare.com`.

## Если ссылка перестала открываться

1. Убедиться, что preview-сервер всё ещё слушает порт `4173`.
2. Перезапустить команду `cloudflared` выше и взять новый адрес из вывода.
3. После первого открытия с сетью дождаться загрузки, затем закрыть и заново открыть PWA. После этого можно включать авиарежим: экран должен появляться сразу. Если на iPhone видна старая версия интерфейса, удалить ярлык Setlist с экрана «Домой» и установить его по новому URL заново.
