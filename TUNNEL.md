# Локальный запуск Setlist PWA с HTTPS

PWA и backend запускаются в Docker. Nginx внутри PWA-контейнера проксирует `/v1` к API на Mac, поэтому телефон видит один HTTPS-origin. Quick Tunnel доступен из мобильной сети и не требует общей Wi-Fi сети.

## Запуск

1. Убедитесь, что Docker Desktop запущен и backend healthy:

   ```sh
   docker compose ps
   curl -f http://localhost:3300/health
   ```

2. Из проекта PWA выполните:

   ```sh
   docker compose --env-file .env.container up -d --build
   ```

3. В отдельном терминале запустите туннель:

   ```sh
   cloudflared tunnel --url http://localhost:4173 --no-autoupdate
   ```

   Оставьте оба контейнера и `cloudflared` запущенными. Quick Tunnel временный; после перезапуска возьмите новый URL из вывода команды.

## iPhone без общей Wi-Fi

1. Подключите iPhone к Mac кабелем USB и нажмите «Доверять этому компьютеру», если появится запрос. Кабель нужен для Safari Web Inspector; для открытия страницы телефон использует мобильный интернет.
2. На iPhone откройте в Safari URL `https://…trycloudflare.com`, который выдал `cloudflared`.
3. Дождитесь, пока библиотека загрузится и покажет время обновления. Затем выберите «Поделиться» → «На экран Домой».
4. Откройте Setlist с экрана Домой. Для офлайн-проверки сначала дождитесь полной синхронизации, затем включите авиарежим и запустите приложение повторно.

Для удалённой отладки включите на iPhone «Настройки» → «Safari» → «Дополнения» → «Веб-инспектор». На Mac откройте Safari → «Настройки» → «Дополнения» → «Показывать функции для веб-разработчиков», затем меню «Разработка» → iPhone → вкладка Setlist.

## Остановка

Остановите `cloudflared` сочетанием Ctrl+C. Контейнер PWA можно остановить командой `docker compose --env-file .env.container down`. Backend и его данные при этом остаются запущенными. Не используйте `down -v`, если не хотите удалить данные backend.

Quick Tunnel публикует приложение и публичный API в интернете без авторизации. Не оставляйте в тестовой библиотеке данные, которые нельзя показывать посторонним. URL временный; для постоянного доступа нужен настроенный именованный туннель и отдельная схема защиты API.
