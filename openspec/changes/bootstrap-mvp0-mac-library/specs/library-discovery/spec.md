# Spec Delta

## Purpose

Даёт мгновенный локальный доступ к репертуару через установленную PWA: пользователь видит библиотеку, находит песню по её данным и запускает сохранённый плейбэк без сети.

## ADDED Requirements

### Requirement: Установка и автономный запуск PWA
Система SHALL предоставлять установленную на экран «Домой» iPhone версию приложения. После хотя бы одного успешного запуска при наличии сети система MUST открывать собственный интерфейс в авиарежиме, не показывая ошибку загрузки приложения.

#### Scenario: Открытие установленного приложения в авиарежиме
- **WHEN** пользователь устанавливает приложение из Safari, один раз успешно открывает его с сетью, закрывает его и включает авиарежим
- **THEN** повторное открытие с экрана «Домой» показывает локальный интерфейс библиотеки

### Requirement: Просмотр локальной библиотеки
Система SHALL отображать список всех локально сохранённых песен с названием и, если он задан, исполнителем. Из списка пользователь MUST иметь возможность открыть карточку выбранной песни.

#### Scenario: Открытие песни из библиотеки
- **WHEN** пользователь выбирает песню из списка библиотеки
- **THEN** система открывает её карточку с заметками и вложениями

### Requirement: Локальный текстовый поиск
Система SHALL искать без сетевого запроса по названию, исполнителю и заметкам сохранённых песен. Поиск MUST быть нечувствителен к регистру и обновлять список при изменении запроса.

#### Scenario: Поиск по исполнителю
- **WHEN** пользователь вводит часть имени исполнителя в строку поиска
- **THEN** система показывает песни, у которых исполнитель содержит этот текст независимо от регистра

#### Scenario: Поиск по заметкам
- **WHEN** пользователь вводит фразу, содержащуюся в заметках песни
- **THEN** система показывает эту песню в результатах

#### Scenario: Нет совпадений
- **WHEN** запрос не совпадает ни с одной сохранённой песней
- **THEN** система показывает пустое состояние без ложных результатов

### Requirement: Локальное воспроизведение плейбэка
Система SHALL предоставлять элементы управления воспроизведением для MP3-вложения песни. При отсутствии сети воспроизведение MUST использовать локально сохранённый файл.

#### Scenario: Запуск плейбэка офлайн
- **WHEN** пользователь открывает песню без сети и запускает её сохранённый MP3
- **THEN** воспроизведение начинается без обращения к удалённому сервису

### Requirement: Проверка офлайн-готовности на iPhone
Система MUST иметь воспроизводимый сценарий приёмки офлайн-готовности на целевом iPhone: библиотека с реальными изображениями и MP3 сохраняется, установленная PWA перезапускается, затем в авиарежиме выполняются поиск, просмотр изображения и запуск плейбэка. Система SHALL считать PWA-подход подтверждённым только при успешном завершении этого сценария.

#### Scenario: Успешная офлайн-приёмка
- **WHEN** пользователь выполняет сценарий офлайн-приёмки с набором реальных песен на целевом iPhone
- **THEN** поиск, изображение и MP3 работают без сетевого соединения после перезапуска приложения
