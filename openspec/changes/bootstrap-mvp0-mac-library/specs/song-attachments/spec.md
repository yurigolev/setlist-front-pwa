# Spec Delta

## Purpose

Позволяет быстро прикреплять к песне локальные скриншоты аккордов и MP3-плейбэки, чтобы они были доступны без повторной загрузки из сети.

## ADDED Requirements

### Requirement: Добавление вложений перетаскиванием
Система SHALL принимать выбор одного или нескольких файлов на форме песни и SHALL принимать их перетаскивание там, где это поддерживает устройство. Система MUST принимать изображения в форматах PNG, JPEG и WebP, а также аудио в формате MP3, и связывать принятый файл с текущей песней.

#### Scenario: Добавление скрина и плейбэка
- **WHEN** пользователь перетаскивает PNG и MP3 на новую песню и сохраняет её
- **THEN** оба файла отображаются среди вложений этой песни

#### Scenario: Добавление с iPhone через выбор файла
- **WHEN** пользователь выбирает PNG и MP3 через системный выбор файлов на iPhone и сохраняет песню
- **THEN** оба файла отображаются среди вложений этой песни

#### Scenario: Неподдерживаемый файл
- **WHEN** пользователь перетаскивает файл неподдерживаемого типа
- **THEN** система не прикрепляет файл и показывает понятное сообщение об ограничении форматов

### Requirement: Локальная доступность вложений
Система MUST хранить принятое содержимое вложения локально вместе с библиотекой, а не только ссылку на исходный файл. После перезапуска приложения система SHALL показывать ранее сохранённые изображения и предоставлять MP3 для воспроизведения без сети.

#### Scenario: Открытие сохранённого изображения офлайн
- **WHEN** пользователь открывает ранее сохранённую песню без сетевого соединения
- **THEN** система показывает прикреплённое изображение аккордов

### Requirement: Предсказуемая ошибка сохранения файла
Если локальное хранилище не может сохранить вложение, система MUST сохранить только уже успешно подтверждённые данные и явно сообщить, какой файл не был добавлен. Система MUST не показывать несуществующее вложение как сохранённое.

#### Scenario: Недостаточно локального места
- **WHEN** хранилище отклоняет запись MP3
- **THEN** система показывает ошибку для этого MP3 и не отображает его как доступный плейбэк
